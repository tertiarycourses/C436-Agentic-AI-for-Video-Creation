# Harbour Bean Video Skill

## Use this skill when

The learner wants a short Harbour Bean video that follows the saved brand, tone and caption style.

## Creative rules

1. Keep one helpful message per video.
2. Use cream backgrounds, teal accents and warm natural light.
3. Write short readable captions and keep movement steady.
4. Use Hook - Value - Proof - Action for the story.
5. Show a draft and ask for review before final output.

## Avoid

Flashing text, dramatic spins, cluttered frames, fake claims, changed logos and unapproved assets.
