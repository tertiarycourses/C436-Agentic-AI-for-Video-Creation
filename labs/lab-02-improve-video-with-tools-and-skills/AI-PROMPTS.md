# Video Prompts for Lab 02

## Main Hermes prompt

```text
Improve my first cafe video without changing its main message. Use the available video tools and skills only where they help. Strengthen the opening, keep one visual style, add clean captions, apply the supplied Harbour Bean colours and calm tone, and end with one clear call to action. Show which tool or skill you will use for each improvement before creating version two. Return a side-by-side review of version one and version two.
```

## Tool-choice prompt

`Review this video idea and recommend the smallest useful toolkit. For each improvement, name the job first and then the tool or skill. Prefer Remotion for branded text and motion graphics, Manim for an explanatory diagram, Higgsfield for a generated cinematic shot, and an editor or FFmpeg for final assembly.`

## Style prompt

`Keep the message unchanged. Use warm cream backgrounds, teal accents, short captions, steady movement and a calm helpful voice. Avoid flashing text, dramatic zooms and invented claims. Show me a style frame before changing the whole video.`


## Review prompt

```text
Review the result as a first-time viewer. Tell me what is clear, what is confusing, where attention drops, whether the visual style stays consistent, and the three changes with the greatest impact. Refer to exact times or shot numbers.
```

## Revision prompt

```text
Create a new version that changes only the approved review points. Keep the story message, approved references and successful shots unchanged. Show me what changed before replacing the current draft.
```
