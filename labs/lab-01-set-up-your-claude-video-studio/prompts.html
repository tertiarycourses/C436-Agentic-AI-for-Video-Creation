Lab 01 — Set Up Your Claude Video Studio

Claude Desktop — skills, the Higgsfield connector and a project · about 30 minutes

Install the tools once so every later lab is one prompt away: Claude calls the right skill and the right Higgsfield tool by name.

Steps

  1. Sign up for Higgsfield — Open the sign-up link on the labs page and start the free 3-day trial (100 credits, usable through the Claude connector), or a paid plan.
  2. Turn on code and files — Claude Desktop: Settings > Capabilities > Code execution and file creation.
  3. Upload five skills — Customize > Skills > + > Upload a skill. Upload each ZIP in assets/skills and switch it on.
  4. Connect Higgsfield — Customize > Connectors > + > Add custom connector. Name Higgsfield, URL https://mcp.higgsfield.ai/mcp, Connect, sign in.
  5. Create the project — + New Project "Kopi & Coins – Ep1 micro-drama (TikTok)". Paste the instructions from project-ep01-setup.pdf; add studio-brief.pdf to its knowledge.
  6. Test tools and skills — Prompt A calls balance, models_explore and presets_show (no generation). Prompt B lists the skills in pipeline order.
  7. Install LahLah Video — Prompt C: Claude detects Mac or Windows, runs the one-line installer and opens the editor.

Prompts

Change only the [HIGHLIGHTED] words, then Copy and paste into the Claude project chat.

PROMPT A — test the Higgsfield tools (no generation)
Check the Higgsfield connector without generating anything.

1. Call balance and tell me my credits and plan.
2. Call models_explore and recommend two video models for a
   9:16, 5-second image-to-video shot: one cheap low-res draft
   model and one final-quality model, with the credit cost of
   each at 480p or 720p and at 1080p.
3. Call presets_show and list ten camera presets by name.

List every Higgsfield tool you can call, one line each. Do not
call any generate_ tool.
PROMPT B — test the skills
List the skills you can use in this project. For each one give:
its name, the job it does, the words in my request that would
make you load it, and what it hands to the next skill.

Then tell me the order the five video skills run in for one
episode, from idea to publish.
PROMPT C — install LahLah Video with Claude
Install LahLah Video on this computer. Detect whether I am on macOS or Windows. On macOS run: curl -fsSL https://raw.githubusercontent.com/alfredang/LahLahVideo/main/install/install.sh | bash . On Windows run in PowerShell: irm https://raw.githubusercontent.com/alfredang/LahLahVideo/main/install/install.ps1 | iex . Show me each command before you run it, then confirm that LahLah Video opens.

Check your work

  • Five skills appear under Customize > Skills and are switched on.
  • Higgsfield shows as connected, and Prompt A returned a real credit balance from the balance tool.
  • Claude named a low-res draft model and a final model from models_explore, with costs, and ten presets from presets_show.
  • The project exists with its instructions saved and studio-brief.pdf in its knowledge.
  • Claude listed the five skills in pipeline order.
  • LahLah Video opens on your computer.
