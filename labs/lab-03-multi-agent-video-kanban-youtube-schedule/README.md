# Lab 03 Improve the Video with a Multi-Agent Team

**Course:** Agentic AI for Video Creation (`C436`)
**Version:** v3.0
**Main result:** team-video.mp4, kanban-export.json, audit-review.md, private-upload-preview.json and schedule-preview.json

## Goal

Create five Hermes profiles, coordinate them on Kanban, improve the video, prepare a private YouTube upload and set a paused schedule.

## What you will use

- `data/agent-profiles.yaml`
- `data/kanban-board.csv`
- `starter/team-orchestrator-prompt.md`
- `starter/youtube-and-schedule-prompt.md`
- `AI-PROMPTS.md` and `AI-PROMPTS.pdf` - copy-ready prompts and examples.
- `evidence/checklist.md` and `evidence/checklist.pdf` - a simple review checklist.

## Steps

1. Create five profiles
2. Build Kanban
3. Run research and script
4. Create and audit video
5. Upload privately
6. Schedule pipeline

1. Open this lab folder as the project in Hermes Desktop.
2. Read the examples in `AI-PROMPTS.md` before writing your own version.
3. Ask Hermes to show the creative plan before it creates or publishes anything.
4. Review the output as a viewer: Is the story clear? Does every shot belong? Is the style consistent?
5. Save the draft, your feedback and the improved version in the named output folder.

## Success check

Five distinct profiles and a dependency-based Kanban board exist, the first video is improved through the team, YouTube is prepared as private, and the schedule remains paused until approval.

## If something goes wrong

- If Hermes cannot see a file, confirm that this lab folder is the current project.
- If the model or service is unavailable, record what you see and use the trainer-approved option.
- If the result looks random, simplify the prompt and describe one shot at a time.
- If characters or locations change, repeat the reference image and continuity details in every shot prompt.
- If YouTube or scheduling is not connected, create a preview and stop before publishing.

## Safety

Use only supplied or authorised images, audio and facts. Do not paste passwords, API keys or private account details into prompts or screenshots. Keep practice uploads private until a person approves publication.
