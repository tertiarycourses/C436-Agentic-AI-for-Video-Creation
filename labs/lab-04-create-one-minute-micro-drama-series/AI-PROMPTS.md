# Video Prompts for Lab 04

## Main Hermes prompt

```text
Create a one-minute pilot for a micro-drama series called The Last Cup. The recurring setting is a warm neighbourhood cafe in Singapore. The lead is Mei, 28, shoulder-length black hair, teal overshirt, cream apron, observant expression and gentle measured speech. First write a six-beat story with a hook, set-up, complication, choice, reveal and emotional final image. Then create one prompt per shot. Repeat the character, wardrobe, location, lighting and screen-direction continuity in every prompt. Use the same approved reference images for all shots. After assembly, ask the Auditor to compare adjacent shots and list any continuity change before approval.
```

## Character consistency prompt

`Use the same approved reference image for Mei in every shot. Mei is 28, with shoulder-length black hair, a teal overshirt, cream apron, observant expression and gentle measured speech. Do not change her face, age, hair, wardrobe or manner.`

## Shot prompt pattern

`SHOT [number], [duration]. Same Mei and same morning cafe as the references. [Framing] of Mei [single action]. Camera [one movement]. Mood [emotion]. Continue [prop and screen direction] from the previous shot. Keep [character, wardrobe, location and lighting] unchanged. Avoid [specific unwanted changes].`

## Episode prompt

`Write a one-minute episode with six beats: hook, set-up, complication, choice, reveal and emotional final image. Limit each shot to one action. Repeat the character and location continuity line in every shot prompt. End with an unresolved emotional question that invites the next episode.`


## Review prompt

```text
Review the result as a first-time viewer. Tell me what is clear, what is confusing, where attention drops, whether the visual style stays consistent, and the three changes with the greatest impact. Refer to exact times or shot numbers.
```

## Revision prompt

```text
Create a new version that changes only the approved review points. Keep the story message, approved references and successful shots unchanged. Show me what changed before replacing the current draft.
```
