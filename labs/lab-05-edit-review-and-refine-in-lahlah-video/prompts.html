Lab 05 — Edit, Review and Refine in LahLah Video

LahLah Video (or CapCut) + Claude Desktop · about 80 minutes

Assemble the episode, assess it against the story and the technical parameters, and propose and make the changes that improve it.

Steps

  1. Open the edit — LahLah Video > Open edit > lahlah-edit.json. No credits left? Open mock-clips/lahlah-edit.json instead.
  2. Finish the rough cut — Clips speak and music is laid. Sit the music under the voices, add the end card text, check captions.
  3. Export v1 — Export for TikTok: 1080x1920, 30 fps, H.264 MP4.
  4. Story pass — Watch on your phone. Prompt A: a scene-by-scene story review with Claude.
  5. Technical pass — Read the export info; Prompt B turns your readings into a QC report with PASS or FAIL.
  6. Fix three things — One re-made shot in Higgsfield (Prompt C: low-res draft, then 1080p), one audio fix and one caption or text fix in LahLah Video.
  7. Export v2 and re-check — Re-run the failed parameters. Record each fix in the fix log.

continuity notes [NOTES].

Check each against the editing standards in this project.
Return a table: parameter, value, target, PASS or FAIL,
evidence, fix. Use the cheapest fix that works.
PROMPT C — re-make one shot (higgsfield-video skill)
Use the higgsfield-video skill. Re-make [SHOT_ID] only, from the
approved reference still, with this change: [CHANGE].
Camera [CAMERA_MOVE]. Draft it low-res first and show me; only
after I approve, upgrade it to 1080p on the final model. Show
the cost of each step, file both jobs in the Ep1 Higgsfield
folder, and update lahlah-edit.json with the new src.
COMMANDS — read the file (optional, FFmpeg)
# resolution, frame rate and duration
ffprobe -v error -select_streams v:0 \
  -show_entries stream=width,height,r_frame_rate:format=duration \
  -of default=nw=1 EP01_v1.mp4

# integrated loudness (LUFS) and true peak (dBTP)
ffmpeg -i EP01_v1.mp4 -af loudnorm=print_format=summary -f null -

  • Three fixes made — one in Higgsfield (drafted low-res first), two in the editor — each in the fix log.
  • EP01_v2.mp4 passes every parameter that failed in v1.
  • Screenshots of the LahLah Video timeline and the export settings saved as evidence.
