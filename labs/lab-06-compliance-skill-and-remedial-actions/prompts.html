Lab 06 — Build a Compliance Skill and Plan Remedial Actions

Claude Desktop — your own skill: kopi-compliance-review · about 80 minutes

Package the studio's standards as a Claude skill, run it on Episode 1, and turn every finding into a remedial action with an owner and a check.

Steps

  1. Read the skill — Open standards.pdf: the rules the skill checks — platform, loudness, captions, rights, PDPA, money messaging, AI labels.
  2. Install it — Customize > Skills > + > Upload a skill > kopi-compliance-review.zip. Switch it on.
  3. Run the review — Prompt A: Claude calls the skill on EP01_v2 with your QC report and episode-01-v2-notes.pdf.
  4. Plan the remedies — Prompt B: one row per finding — standard, risk, action, owner, check, prevention.
  5. Fix the high risks — Re-voice or re-caption in LahLah Video; re-make a shot through the higgsfield-video skill if needed (low-res draft first).
  6. Re-check and improve the skill — Run the review on EP01_v3. Prompt C adds one new rule to the skill so the issue cannot return.

Prompts

Change only the [HIGHLIGHTED] words, then Copy and paste into the Claude project chat.

PROMPT A — run the compliance review
Use the kopi-compliance-review skill on Episode 1 v2.

Evidence: my QC report, captions.srt, the approved script, the
music licence note and episode-01-v2-notes.pdf (attached).

One row per finding: standard, evidence (timecode, frame or
reading), risk (high, medium, low) with a reason, and the
remedial action. Mark anything you cannot verify as
UNVERIFIED. Do not approve the episode.
PROMPT B — remedial action plan
Turn the findings into a remedial action plan as CSV:
finding, standard, risk, corrective action, owner, due, how
we verify the fix, how we prevent it recurring.

Order by risk, high first. Where the fix is a re-make, name the
shot ID and the higgsfield-video prompt change, drafted low-res
before 1080p.
PROMPT C — improve the skill
The finding "[FINDING]" came from a gap in our process. Draft
one new rule for the kopi-compliance-review skill that would
catch it next time: the rule, how to check it, the evidence
to record. Show the updated SKILL.md section so I can paste
it in and re-upload the skill.

Check your work

  • kopi-compliance-review shows under Customize > Skills and is on.
  • The compliance report lists every finding with standard, evidence and risk.
  • The remedial plan has an owner, a check and a prevention for each finding, high risks first.
  • High-risk findings are fixed in EP01_v3.
  • The re-run review shows no high-risk findings.
  • One new rule drafted for the skill.
